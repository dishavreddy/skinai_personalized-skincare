# skinai_personalized-skincare
SkinAI

AI powered skincare analysis and personalized skincare insights platform

Overview

SkinAI is a modern AI skincare web application that allows users to upload a selfie and receive intelligent skin analysis including hydration glow texture acne and skincare recommendations

The platform is designed with a clean premium human centered UI inspired by modern wellness apps and luxury skincare brands
